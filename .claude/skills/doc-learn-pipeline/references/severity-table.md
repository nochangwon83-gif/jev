# 단계별 경중·모델 배정표

`run_stage.py`가 이 표를 읽는다. '배정 등급'은 jev 판단이 없거나 불확실할 때 쓰는 **기준값**이고, 실제 등급은 jev가 판단한다(아래 운영 규칙).
**표의 형식(열 이름, `|` 구분)을 바꾸지 말 것.** 값은 사용자가 조정한다(명세서 8장 제안값으로 시작).

- 등급 이름: `fast`(Haiku) · `balanced`(Sonnet) · `strong`(Opus) · `none`(모델 미사용)
- `long`(Fable)은 비용을 확인하기 전까지 쓰지 않는다.
- `strong 고정`이 `예`인 단계는 jev 판단과 무관하게 strong(Opus)으로 실행한다(`--execute`가 `--model opus`로 고정해 띄움).

| 단계ID | 단계 작업 | 경중 | 배정 등급 | strong 고정 | 근거 | 작업 설명(jev 전달) |
|---|---|---|---|---|---|---|
| S0 | 폴더 스캔·해시 산출 | 없음 | none | 아니오 | 결정적 작업(scan.py) | 폴더의 파일 목록과 해시를 스크립트로 만든다. 판단 없음. |
| S1a | 제목 모드 분류 | 낮음 | fast | 아니오 | 이름 패턴 판단, 사용자 승인 단계가 뒤에 있음 | 파일 이름과 폴더 이름만 보고 분류 폴더를 제안한다. 결과는 사람이 CSV에서 승인한다. |
| S1b | 내용 모드 분류 | 중간 | balanced | 아니오 | 본문 이해 필요 | 문서 앞부분 본문을 읽고 문서 종류·장르를 판단해 분류 폴더를 제안한다. 결과는 사람이 승인한다. |
| S1c | 분류 신뢰도 낮은 건 재판정 | 중간~높음 | strong | 아니오 | 오분류 시 자료 혼재 | 자동 분류 신뢰도가 낮은 파일의 본문을 읽고 분류를 다시 판단한다. 오분류 시 자료가 섞인다. |
| S2n | 카드 작성(웹소설) | 중간 | balanced | 아니오 | 문체·전개 분석 | 웹소설 회차를 읽고 문체·전개·인물 화술을 분석한 카드를 쓴다. 원문 인용은 40자 이하로 짧게. |
| S2l | 카드 작성(법무: 조항·서면 인용) | 높음 | strong | 예 | 원문 정확성이 결과물에 직접 영향 | 계약서 조항·소송서면을 읽고 원문 그대로의 인용과 쪽·조항 위치를 담은 카드를 쓴다. 인용 오류는 법률 산출물에 직접 영향. |
| S3 | 주제별 학습노트 작성 | 높음 | strong | 아니오 | 여러 카드 종합, 패턴 판단 | 검증된 여러 카드를 종합해 주제별 학습노트를 쓰고 반복 패턴을 판단한다. 모든 문장에 근거 카드 ID를 단다. |
| S4 | 표본 검증(원문 대조) | 중간 | balanced | 아니오 | 스크립트 + balanced 이상, 작성자와 다른 세션에서 독립 수행 | 카드 인용을 원본과 다시 대조하는 스크립트를 실행하고 결과를 보고한다. |
| S5 | 스킬 반영 제안서 작성 | 높음 | strong | 예 | 스킬 변경이 이후 모든 산출에 영향 | 학습노트와 기존 법률·웹소설 스킬 지침을 대조해 변경 제안서를 쓴다. 채택되면 이후 모든 산출물에 영향. |

## 운영 규칙 (명세서 8장 + jev 직접 판단)

1. **jev가 단계마다 경중·등급을 직접 판단한다.** `run_stage.py`가 TypeSafe Jev(System One API)에
   위 표의 '단계 작업'·'작업 설명(jev 전달)'과 파일 개수·형식만 보내고, 경중 점수(0~3)와 등급(fast/balanced/strong)을 받는다.
   문서 본문·인용문·사건명·당사자명·파일명은 보내지 않는다(전송 직전 `check_prompts.py`로 점검, 위반 시 전송 안 함).
2. jev 답을 코드 규칙으로 최종 확정한다(`jev_route.py`의 `decide`):
   - jev 실패·시간 초과·키 없음 → 이 표의 '배정 등급' 사용.
   - jev 신뢰도가 `jev_min_confidence`(기본 0.6) 미만 → 이 표보다 낮추지 않는다.
   - jev 등급과 jev 경중 점수가 어긋나면 높은 쪽을 쓴다.
   - `strong 고정`이 `예`인 단계(S2l 법률 인용, S5 스킬 반영)는 jev 답과 무관하게 strong.
   - long(Fable)은 쓰지 않는다. `none` 단계(S0)는 jev를 부르지 않는다.
3. `--execute`를 주면 확정 등급의 모델로 **새 Claude Code 세션**을 띄워 단계 프롬프트를 실행한다
   (fast=haiku, balanced=sonnet, strong=opus, `config.json`의 `claude_models`에서 변경).
4. `JEV_API_KEY`는 스킬 폴더의 `.env`에만 둔다(`TYPESAFE_API_KEY`도 인식).
5. 모든 판단은 `_state/jev_decisions.jsonl`에 요청·응답·최종 등급과 사유로 남는다. `pipeline_status.py`가 등급별 건수를 보여준다.
