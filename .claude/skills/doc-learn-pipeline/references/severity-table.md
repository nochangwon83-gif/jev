# 단계별 경중·모델 배정표

`run_stage.py`가 이 표를 읽어 단계마다 배정 등급과 strong 고정 여부를 정한다.
**표의 형식(열 이름, `|` 구분)을 바꾸지 말 것.** 값은 사용자가 조정한다(명세서 8장 제안값으로 시작).

- 등급 이름: `fast`(Haiku) · `balanced`(Sonnet) · `strong`(Opus) · `none`(모델 미사용)
- `long`(Fable)은 비용을 확인하기 전까지 쓰지 않는다.
- `strong 고정`이 `예`인 단계는 새 세션에서 `/model`로 strong을 직접 골라 라우팅이 등급을 내리지 못하게 한다.

| 단계ID | 단계 작업 | 경중 | 배정 등급 | strong 고정 | 근거 |
|---|---|---|---|---|---|
| S0 | 폴더 스캔·해시 산출 | 없음 | none | 아니오 | 결정적 작업(scan.py) |
| S1a | 제목 모드 분류 | 낮음 | fast | 아니오 | 이름 패턴 판단, 사용자 승인 단계가 뒤에 있음 |
| S1b | 내용 모드 분류 | 중간 | balanced | 아니오 | 본문 이해 필요 |
| S1c | 분류 신뢰도 낮은 건 재판정 | 중간~높음 | strong | 아니오 | 오분류 시 자료 혼재 |
| S2n | 카드 작성(웹소설) | 중간 | balanced | 아니오 | 문체·전개 분석 |
| S2l | 카드 작성(법무: 조항·서면 인용) | 높음 | strong | 예 | 원문 정확성이 결과물에 직접 영향 |
| S3 | 주제별 학습노트 작성 | 높음 | strong | 아니오 | 여러 카드 종합, 패턴 판단 |
| S4 | 표본 검증(원문 대조) | 중간 | balanced | 아니오 | 스크립트 + balanced 이상, 작성자와 다른 세션에서 독립 수행 |
| S5 | 스킬 반영 제안서 작성 | 높음 | strong | 예 | 스킬 변경이 이후 모든 산출에 영향 |

## 운영 규칙 (명세서 8장)

1. 단계마다 **새 세션**으로 실행해 대화 길이 때문에 등급이 고정되지 않게 한다.
2. 법률 인용(S2l)·스킬 반영(S5) 단계는 `/model`로 strong을 직접 고정한다.
3. 실행 전 `run_stage.py --jev-try`로 배정 등급을 미리 보고, 표와 다르면 표시한다.
   (`jev try` 명령이 설치된 jev에 있는지는 **확인 불가** — 없으면 스크립트가 그렇게 보고한다.)
4. `JEV_API_KEY`는 스킬 폴더의 `.env`에만 둔다. 단계 프롬프트에는 작업 유형과 파일 번호만 넣는다(`check_prompts.py`가 점검).
5. `run_stage.py --record-stats`로 단계별 `jev stats` 출력을 `_state/jev_stats.log`에 남기고 이 표를 조정한다.

확인 불가: 설치된 jev가 위 명령·변수를 지원하는지, `JEV_PIN`이 실제로 모델을 고정하는지.
