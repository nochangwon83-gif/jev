# 학습자료 카드 양식

카드는 **문서 한 건당 하나**다. 요약이 아니라 **확인 가능한 근거 모음**이다.
Claude는 원본 파일을 직접 읽고 아래 형식의 초안 JSON을 작성한 뒤 `make_card.py --draft`로 등록한다.
등록된 카드는 `_output/cards/C-0001.json`(기준 데이터)과 `C-0001.md`(읽기용)로 저장된다.

## 공통 필드

| 필드 | 작성자 | 규칙 |
|---|---|---|
| `card_id` | 스크립트 | `C-0001` 형식, 자동 부여 |
| `file_id` | Claude | manifest의 파일 번호(`F0001`) |
| `source_path`, `source_sha256`, `learned_at` | 스크립트 | manifest와 원본에서 자동 기록 |
| `field` | Claude | `법무` 또는 `웹소설` |
| `type` | Claude | `계약서` / `소송기록` / `웹소설` |
| `summary` | Claude | 핵심 요지 **3문장 이내**(목록 항목 하나가 한 문장) |
| `quotes` | Claude | `[{"text": 원문 그대로, "loc": "p.3" / "문단 12" / "줄 5" / "제5조"}]`. 위치를 모르면 `"확인 불가"` |
| `patterns` | Claude | `[{"pattern": 재사용 가능한 패턴, "apply_skill": 적용할 스킬 이름}]` |
| `topics` | Claude | 학습노트 묶음 키. 예: `공사도급/지체상금`, `준비서면/기성금`, `무협/전개` |
| `verification` | 스크립트 | 처음엔 `미완료`, `verify_cards.py` 통과 시 `원문 대조 완료`, 불일치 시 `검증 미완료` |
| `source_state` | 스크립트 | `정상` / `원본 없음` / `원본 변경(개정 필요)` |

값을 원문에서 확인하지 못하면 **추측하지 말고 `"확인 불가"`** 로 적는다. 빈 값도 `확인 불가`로 채워진다.

## 분야별 추가 필드 (`extra`)

| type | 필수 키 | 주의 |
|---|---|---|
| 계약서 | `계약 유형`, `당사자 입장`, `조항`(`[{"번호","문언","loc"}]`), `쟁점` | `조항.문언`은 **조항 단위로 원문 그대로** — 원문 대조 대상 |
| 소송기록 | `사건번호`, `서면 종류`, `주장·반박 대응`, `증거` | 인용의 `loc`에 **쪽 번호** 기재(`p.N`) |
| 웹소설 | `장르`, `문체 특징`, `전개 패턴`, `인물 화술` | 원문 인용은 **한 건당 `novel_quote_max_chars`자(기본 40자) 이하, `novel_max_quotes`건(기본 3건) 이하**. 분석과 짧은 위치 표기 중심 |

## 초안 예시 (계약서)

```json
{
  "file_id": "F0001",
  "field": "법무",
  "type": "계약서",
  "summary": ["지체상금률은 1일 1000분의 1로 정함.", "지체상금 총액 상한은 계약금액의 10%임."],
  "quotes": [{"text": "지체상금의 총액은 계약금액의 100분의 10을 초과하지 아니한다.", "loc": "문단 7"}],
  "patterns": [{"pattern": "지체상금 상한 조항 존재 여부 확인", "apply_skill": "domestic-construction-contract-review"}],
  "topics": ["공사도급/지체상금"],
  "extra": {"계약 유형": "공사도급", "당사자 입장": "확인 불가",
            "조항": [{"번호": "제5조", "문언": "…원문 그대로…", "loc": "문단 7"}], "쟁점": ["지체상금 상한"]}
}
```

## 갱신 규칙

- 새 파일 → 카드 추가.
- 해시가 바뀐 파일 → 같은 카드 ID로 개정(`version`+1). 이전 판은 `_output/cards/_history/`에 보관.
- 원본이 사라진 파일 → 카드를 지우지 않고 `source_state: 원본 없음`으로 표시(`make_card.py --refresh`).
