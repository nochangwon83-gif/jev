# 분류 기준

## 확정된 분류 체계

- **기존 폴더 상위 구조를 그대로 쓴다** (사용자 결정, 2026-09-29 사전 점검).
  - 파일이 이미 상위 폴더(예: `계약서`, `소송기록`) 안에 있으면 그 상위 폴더를 유지한다.
  - 스킬은 그 아래 **하위 폴더만 제안**한다.
  - 상위 폴더가 아래 규칙의 어느 `top`에도 해당하지 않으면(예: `미분류`, 루트 바로 아래) 규칙으로 상위 폴더까지 제안하되 신뢰도를 낮춘다.
- 제안 경로 = `dest_roots[분야]` / 상위 폴더 / 하위 폴더 / 원래 파일명
- 웹소설은 장르 폴더를 상위 폴더로 보고 하위 폴더를 두지 않는다(`sub`가 빈 값). 이미 장르 폴더에 있으면 그대로 유지하고(신뢰도 0.7), `기타` 등 알 수 없는 폴더에 있으면 장르를 제안한다.

## 규칙 표 (초안 — 사용자가 고쳐 쓴다)

아래 키워드는 **초안**이다. 실제 폴더의 이름 관행은 스캔 결과를 보고 사용자가 확정한다.
`classify_plan.py`는 아래 JSON 블록만 읽는다.

- `title`: 제목 모드에서 파일명·상위 폴더명과 비교하는 키워드
- `content`: 내용 모드에서 본문 앞부분(`content_mode_max_chars` 이내)과 비교하는 키워드
- `pattern`: 파일명에 대한 정규식(맞으면 강한 근거)

## 신뢰도 산정 (스크립트 규칙, 결정적)

| 근거 | 신뢰도 |
|---|---|
| 파일명 정규식(`pattern`) 일치 + 키워드 일치 | 0.9 |
| 파일명에 키워드 일치 | 0.75 |
| 상위 폴더명에만 키워드 일치 | 0.5 |
| 내용 모드: 본문 키워드 2개 이상 | 0.8 |
| 내용 모드: 본문 키워드 1개 | 0.6 |
| 일치 없음 → 하위 폴더 `미분류` | 0.2 |
| 두 규칙 이상이 같은 점수로 겹침 | 위 값 − 0.2 |
| 기존 상위 폴더가 규칙에 없어 상위 폴더까지 제안 | 위 값 − 0.1 |
| 웹소설: 기존 장르 폴더 유지(하위 폴더 없음) | 0.7 |

`title_confidence_threshold`(기본 0.6) 미만은 **자동 모드**에서 내용 모드로 올려 다시 판정한다.
그래도 미달이면 CSV에 남겨 사람이 정한다(경중표 S1c: strong 등급 재판정 대상).
